# Test scenarios: Addresses and domain names

Scenarios for the header address parser (RFC 5322), the envelope address parser (RFC 5321), the lookup form of domain names, and the checks that read addresses. Conventions are in [README.md](README.md).

Scenarios based on the examples in RFC 5322 Appendix A keep the structure of the example, with its domains moved under `.invalid`. A table gives a `U+` number for each code point it can't show as a character.

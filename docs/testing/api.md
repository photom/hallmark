# Test scenarios: API validation

Scenarios for the validation rules of the [API reference](https://photom.github.io/hallmark/api/hallmark/): each `API-` scenario tests the rule with the same number, such as API-101 for VAL-101. A rule that a scenario in another file already tests names that scenario instead. Conventions are in [README.md](README.md).
